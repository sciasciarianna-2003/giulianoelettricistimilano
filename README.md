# Giuliano Elettricisti Milano

Sito web di Giuliano Elettricisti Milano: pronto intervento elettricista, impianti elettrici, quadri e certificazioni a Milano e hinterland.

## File

- `index.html` – home page
- `privacy-policy.html`, `cookie-policy.html` – pagine legali (stile in `legal.css`)
- `logo.png` – logo originale, `logo-nav.png` – logo ritagliato per la barra in alto

## Vedere il sito in locale

```bash
python3 -m http.server 8080
```

Poi apri http://localhost:8080
